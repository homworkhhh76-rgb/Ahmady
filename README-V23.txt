الأحمدي لإدارة عدادات الكهرباء — V23

تحديث قائمة الإعدادات:
- بيانات الشبكة القابلة للتعديل داخل التطبيق.
- 7 قوالب رسائل أساسية + قوالب استعلامية مخصصة قابلة للإضافة والتعديل والحذف.
- ربط قوالب الملخص والفواتير والتحصيل والإرسال وتحويل الأموال برسائل المشتركين.
- إجراء سريع لإرسال رسالة استعلامية لمشترك واحد أو عدة مشتركين.
- اللغة: العربية + وضع English تجريبي للصفحات الداعمة.
- المظهر: ليلي/نهاري، ألوان ثيم متعددة، وجدولة زمنية للوضع الداكن.
- الدعم الفني: تفعيل/تعطيل رسائل المشتركين ومركز تواصل داخل التطبيق.
- الإشعارات: تفعيل/تعطيل وإعداد فترة زمنية.
- إدارة الوصول: تجميد الموظفين والمشتركين، وتحديد مناطق العدادات المسموح بها لكل موظف.
- تصدير نسخة إلى ملف الهاتف، والمشاركة عبر قائمة النظام لاختيار Google Drive عند دعم الجهاز.
- تسجيل الخروج من صفحة الإعدادات.

ملاحظات تقنية:
- تعديل اسم المستخدم/كلمة المرور في بطاقة بيانات الشبكة لا يغير بيانات التفعيل في القاعدة الأم.
- خيار English حالياً واجهة تجريبية للصفحات الداعمة وليس ترجمة كاملة لكل التطبيق.
- Google Drive يعتمد على مشاركة الملف من نظام الجهاز، وليس اتصال Google Drive API مباشراً.
