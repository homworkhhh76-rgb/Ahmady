الأحمدي V24 — Cloudflare R2 image storage update

- جميع صور قراءات الفواتير وصور إشعارات الدفعات والإرسالات والمصروفات تُجهز تلقائياً حتى 50KB تقريباً قبل التخزين.
- عند وجود الإنترنت: الصورة تُرفع إلى Cloudflare R2 ويُحفظ رابطها العام داخل بيانات التطبيق/Turso.
- عند عدم وجود الإنترنت: الصورة تُحفظ محلياً بشكل مضغوط، وتبقى العملية كاملة قابلة للحفظ والعمل أوفلاين.
- عند عودة الإنترنت: قبل دفع بيانات الفواتير/الحركات/الإعدادات إلى Turso، تُرفع الصور المحلية أولاً إلى R2 ثم تُستبدل بيانات الصورة بالرابط العام؛ لذلك Turso يستقبل الرابط وليس Base64 للصورة.
- تمت إضافة رفع/تغيير/إزالة شعار الشبكة من الإعدادات > بيانات الشبكة بنفس التخزين R2 ونفس آلية الأوفلاين.
- يوجد شريط تحميل صغير وغير مزعج أثناء تجهيز/رفع الصورة.
- الضغط على سجل فاتورة أو دفعة/إرسال/مصروف/حركة مالية يفتح نافذة تفاصيل، وتظهر فيها الصورة المرفقة إن وجدت.
