الأحمدي — تطبيق المستخدمين V6

الإضافات في هذه النسخة:
- قائمة مستقلة للعدادات ضمن القائمة الرئيسية.
- ثلاث أقسام: جميع العدادات، لوحات التوزيع، مناطق لوحات التوزيع.
- إضافة منطقة، لوحة توزيع، وعداد من زر + في صفحة العدادات.
- رقم العداد يولد تلقائياً بصيغة M0001 ثم M0002...
- العداد مرتبط بمشترك + منطقة + لوحة توزيع + موقع + قراءة افتتاحية + تاريخ + ملاحظات.
- صفحة كل عداد تعرض بياناته، القراءة الأولى والأخيرة، إجمالي الاستهلاك والتكلفة وفواتير العداد مع فلترة زمنية وبحث وترتيب.
- صفحة لوحة التوزيع تعرض عدد العدادات وإجمالي الاستهلاك ثم عدادات اللوحة.
- صفحة المنطقة تعرض بطاقتين: عدادات المنطقة ولوحات التوزيع، ويمكن فتح كل لوحة ثم كل عداد.
- المناطق ولوحات التوزيع مضافة إلى محرك Turso Local-first وتعمل بدون إنترنت وتزامن تلقائياً عند رجوع الاتصال.
- بيانات النسخ السابقة تبقى متوافقة؛ العدادات القديمة تظهر بمنطقة/لوحة غير محددة حتى يتم إنشاء البنية الجديدة.

المشروع Flat: جميع الملفات في مستوى واحد، والبدء من index.html.
