أهم التعديلات:
- بطاقة إجراءات سريعة وزر ترتيب الأيقونات/القوائم مع حفظ الترتيب.
- ترحيب صباح الخير/مساء الخير وإظهار نوع الحساب داخل بطاقة الترحيب.
- ملخص مشتركين جديد: العدد، الاستهلاك، الاستحقاقات، الأعداد، وصافي الاستحقاق.
- تطوير ملف المشترك: نظرة عامة، فواتير، حركات مالية، ملخص كهرباء كامل، آخر فاتورة، والعدادات.
- الشريط السفلي: الرئيسية، المشتركين، العدادات، الفواتير، التدفقات المالية، المزيد.
- مظهر القوائم والإجراءات متزامن مع الثيم.
- تطوير إدارة الموظفين: المسمى الوظيفي، بيانات الدخول، والتجميد.
- إضافة إدارة حسابات المشتركين (قراءة فقط) مع اسم مستخدم/كلمة مرور/تجميد وحذف الحساب دون حذف بيانات المشترك.
- حساب المشترك معزول محلياً ومزامنته سحب فقط لحماية بيانات الشبكة وباقي المشتركين.
- تحديث Service Worker إلى V32 لتجنب بقاء ملفات الواجهة القديمة في الكاش.
